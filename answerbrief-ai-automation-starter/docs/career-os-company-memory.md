# Career OS Company Memory

Company Memory captures reusable knowledge only after a verified successful submission.

Stored knowledge includes:
- ATS and employer identity
- selectors and field mappings
- resume upload strategy
- recurring required questions
- review-page sequence
- submission confirmation patterns

Safety rules:
- Failed attempts do not make a memory reusable.
- Exact employer + ATS + host matches are preferred.
- Generic ATS memories may be used only when they were created from confirmed submissions.
- New observations merge with prior knowledge instead of erasing known-good selectors or mappings.
- Human-only gates remain governed by the blocker and retry policies.
